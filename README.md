1.  Run the code
2.  Click sleep trends
3.  A graph will load, you can switch between heap and map mode at the bottom, the time to load these functions is represented right below the switcher.
4.  Below that you can hover over ranges in the graph, this'll show averages for those ranges based on: Stress, Caffeine, Screen Time, and Work.
5.  Below the graph you can switch which components of the graph you want to visually display by toggle, so you can disable work or only have stress as an option
6.  The quality range box is below the toggle boxes, you can enter 2 sleep quality values and the averages for components. Press enter and it'll gather those averages based on whether the program is on Map or Heap mode. The time taken on this operation will be listed along with the amount of nights.
